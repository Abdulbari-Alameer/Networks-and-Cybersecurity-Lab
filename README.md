## Research

**Automatic Configuration and Performance Analysis of Time Sensitive Networks**
A. Ahmed, M. A. Saeed and V. I. Knmashinsky. Presented at the *CSDY Conference 2022*.

Time Sensitive Networking (TSN) is a set of IEEE 802.1 standards that give Ethernet deterministic, low-latency delivery for industrial and real-time traffic. The paper looks at how TSN networks can be configured automatically and how they perform.
